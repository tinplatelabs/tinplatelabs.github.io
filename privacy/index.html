Privacy

Short version: this site doesn't track you, and the tools don't send your data anywhere.

This website

tinplatelabs.github.io is a static site. It sets no cookies, runs no analytics, loads no third-party scripts or fonts and has no forms. It is hosted on GitHub Pages; GitHub may log technical request data such as IP addresses for security, as described in the GitHub Privacy Statement.

Apify Actors

The Actors run on the Apify platform in your own account. Your inputs and results are stored in your run's storages and follow your Apify data-retention settings and Apify's privacy policy. Tinplate Labs sees aggregate usage and billing data that Apify gives every Actor developer, and does not read your run data. None of the Actors sends data to an LLM or collects telemetry.

Document to Markdown

Files are downloaded into your run, converted there and written only to the run's dataset and key-value store. No third party, no LLM, no telemetry; links inside documents are never followed.

Domain Intel

Reads only public DNS, public registry (RDAP) data and the certificates the domain's own servers present. Registrant personal data is dropped. No LLM, no other third party.

Contact Normalizer

Records are processed inside your run and stored only in its dataset and key-value store. No third party, no LLM. The optional MX check sends e-mail domains, never full addresses, to DNS resolvers.

Image Upscaler

Images are processed inside your run and written only to its key-value store and dataset. No third party, no telemetry; EXIF metadata such as GPS is stripped from the output.

Site Discovery

Fetches only public machine-readable files (robots.txt, sitemaps, llms.txt) from the sites you name. Results go only to your run's dataset. No LLM, no telemetry.

HTTP Request Tool for Agents

Requests go only to the URLs you give (and their redirects). Secrets in headers are redacted in the dataset and log. No third party, no LLM, no telemetry.

Dataset Toolkit

Data is processed only inside your run and stored only in your run's storages. No third party, no LLM.

Image OCR

Images are processed inside your run; results go only to its dataset. No third party, no telemetry, and only the exact URLs you give are fetched.

Transcriber

Files are processed inside your run; results go only to its dataset and key-value store. No speech-to-text API or other third party, no telemetry.

Video Frames

Videos are processed inside your run; results go only to its dataset and key-value store. No third party, no telemetry, and only the exact URLs you give are fetched.

Traefik Labels

Runs entirely inside your IDE with no network access and no telemetry. JetBrains Marketplace handles downloads and any licensing under its own privacy policy.
