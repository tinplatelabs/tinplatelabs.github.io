Upscale photos 2x to 4x in bulk with Real-ESRGAN, faithful to the original, no diffusion.

What it solves

Ordinary resizing makes small product photos, thumbnails and old web images soft and blocky. Diffusion upscalers look sharp but redraw faces, text and objects that were never there.

Image Upscaler uses Real-ESRGAN (realesr-general-x4v3), a compact restoration network that sharpens edges and removes blur, noise and JPEG artifacts without inventing new content. Send a batch of URLs or key-value store files and get upscaled PNG, JPEG or WebP files with one result row per image.

  • Scale 2x, 3x or 4x; up to 500 images per run; one bad image never stops the run.
  • Tunable denoiseStrength from 0 (keep grain) to 100 (clean and smooth).
  • Transparency, grayscale, EXIF rotation and ICC color profile preserved; EXIF metadata (camera, GPS) removed from the output.
  • Price depends on the size of the image you send, not the scale.

Anything that can't be processed becomes an error item with a code and a message that says what to change; the rest of the run carries on.

Limits

  • Input 8 to 4096 px per side, 30 MB per file, up to 500 images per run.
  • Output at most 25 megapixels (4x: inputs up to about 1250x1250 px; 2x: about 2500x2500 px).
  • Animated GIF/WebP and multi-page TIFF: first frame only.
  • No face restoration, no video, no more than 4x in one run (run the output again for 8x).
  • Runs on CPU: about 7 s per input megapixel at the default 16 GB.

Privacy

Images are processed inside your run and written only to its key-value store and dataset. No third party, no telemetry; EXIF metadata such as GPS is stripped from the output. See also the privacy page.

FAQ

Will it change faces or text in my image?

No. Real-ESRGAN sharpens what is there; it has a small field of view and doesn't imagine new faces, words or objects the way diffusion upscalers can. A blurry input stays honest about it.

Which upscale factor should I use?

4x for small images and thumbnails. For inputs larger than about 1250x1250 px use 3x or 2x so the output stays within 25 megapixels; the error message tells you which scale fits.

Can I keep transparency?

Yes. Transparent images keep their alpha channel and come out as PNG (or WebP if you ask for it).

Where are the upscaled files?

In the run's key-value store. Each dataset item has a signed outputUrl that works for anyone you share it with.

Does it cost more at 4x than 2x?

No. You pay by the size of the input image; the scale doesn't change the price.
