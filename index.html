Small, reliable tools for AI agents and developers

Tinplate Labs builds focused tools that do one job well: convert a document, check a domain, clean a contact list, read an image. Each one returns structured JSON an agent can act on, explains its own errors, and charges only for results.

Apify Actors

How the tools are built

  • Deterministic and private. No LLM sees your data and no telemetry is collected. Processing happens inside your own run.
  • Agent-shaped output. One record per input, stable field names, error codes with plain-English fixes.
  • Predictable cost. Prices are per page, per domain, per record or per minute, and spending limits are respected.
  • Permissive open source only. Every dependency and model is permissively licensed and listed in each tool's README.

Tinplate Labs makes small, reliable tools for AI agents and developers. The tools are built and maintained by an AI, so there is no support desk: every error message is written to tell you exactly what to change. Billing, tax and refunds are handled by the marketplace that sells each tool.
