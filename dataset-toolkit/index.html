Dataset Toolkit

Merge and dedupe scraped data (even fuzzy), only new items per run, export to CSV or Excel.

Open Dataset Toolkit in the Apify Store

What it solves

Scraped data rarely arrives in one clean file. It comes from several runs and formats, with duplicates that differ only in case, spacing or a typo, and needs filtering and a particular export format before anyone can use it.

Dataset Toolkit reads Apify datasets and CSV, TSV, JSON, JSON Lines, Excel and Parquet files, merges them, flattens nested JSON, filters with a simple rule language, removes duplicates (exact, normalized or fuzzy), sorts, selects and renames columns, and exports to CSV, XLSX, JSON, JSONL or Parquet with download links. Rows are staged on disk, so a million rows don't run out of memory.

  • Filter without code: price >= 10 and country in ["CA", "US"] and not email empty, parsed safely, never executed.
  • Fuzzy dedupe with RapidFuzz: Acme Corporation Ltd matches ACME Corporaton Ltd.; keep the first, last or most complete row.
  • Only new items: onlyNew: true leaves out rows earlier runs delivered (memory kept in a key-value store in your account, up to 5 million rows), so a scheduled scraper passes on just what is new.
  • Every input read independently: a broken file gets an error in the summary while everything else is processed.
  • Measured: 1,000,000 rows with dedupe, sort and three exports in about 70 s.

Limits

  • Row count limited by disk, not memory; give multi-million-row runs 2 to 4 GB.
  • Files up to 1 GB each; JSON files whose top level is an object are limited to 100 MB.
  • XLSX holds at most 1,048,575 rows; only the first sheet of a workbook is read; old .xls is not supported.
  • At most 100 inputs per run; file URLs must be public.

Use it from an AI agent

Through the Apify MCP server, Claude, ChatGPT, Cursor and other MCP clients can call this Actor as a tool. Add the server with this Actor enabled:

{
  "mcpServers": {
    "apify": {
      "url": "https://mcp.apify.com/?tools=tinplatelabs/dataset-toolkit",
      "headers": {
        "Authorization": "Bearer <APIFY_TOKEN>"
      }
    }
  }
}

The agent calls it with {"items": [{"email": "Ann@X.com "}, {"email": "ann@x.com"}], "dedupe": "normalized", "datasetOutput": "summary"} and reads the summary item's counts and export links.

Or call the Apify API directly. This runs the Actor and returns the dataset items (synchronous runs time out after 300 s; for big batches start a run and read the dataset when it finishes):

curl -s -X POST \
  "https://api.apify.com/v2/acts/tinplatelabs~dataset-toolkit/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"items": [{"email": "Ann@X.com "}, {"email": "ann@x.com"}], "dedupe": "normalized", "datasetOutput": "summary"}'

FAQ

How does fuzzy dedupe work?

Values are normalized and compared with RapidFuzz token sort ratio; a row joins the first earlier group scoring at least fuzzyThreshold (default 90). It catches typos, punctuation and word order. A typo in the very first letter is not caught.

Can I convert a CSV to Excel or Parquet without other changes?

Yes. Give the file in fileUrls and the formats in exportFormats; the cost is $0.002 per started 1,000 rows plus $0.005 per file.

Can it output only items that are new since the last run?

Yes. Set onlyNew: true and the match fields in dedupeFields. Each run leaves out rows an earlier run with the same onlyNewKey delivered and remembers its own. Rows removed by the filter or limit are not remembered. No extra charge: rows read are priced as usual.

Can an agent get just the result links?

Yes. Set datasetOutput: "summary" to get one item with counts and download links instead of every row.

What happens if one input fails?

It gets an error with a code and fix in the summary, and the other inputs are still processed. The run fails only if the input itself is invalid.
