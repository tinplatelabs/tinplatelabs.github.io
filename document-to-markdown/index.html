Document to Markdown

PDF to Markdown, plus Word, Excel, PowerPoint, HTML and scans, for LLMs and RAG, priced per page.

Open Document to Markdown in the Apify Store

What it solves

LLMs read Markdown well and PDFs badly. Copy-pasting text out of a PDF loses tables, merges columns and repeats headers; Office files need a different library for every format; scanned pages have no text at all.

Document to Markdown takes any mix of PDFs, Word, Excel and PowerPoint files, web pages, CSV, text and images and returns Markdown (or typed JSON blocks) with headings, lists and tables intact, plus a page map so an agent can cite or chunk by page. Pages without a text layer go through Tesseract OCR automatically, and only those pay the OCR price.

  • Every common format in one call; the format is detected from the file's content, not its name.
  • Ruled tables in PDFs, Word tables, Excel sheets and HTML tables come out as Markdown tables (or row arrays in JSON).
  • Larger fonts in PDFs become #/##/### headings; bullets become lists.
  • <!-- page N --> markers and a page map of character offsets, document metadata, warnings and a truncated flag.
  • Optional one dataset item per page, ready for embedding.
  • No LLMs, no third-party APIs, no telemetry: the same file always gives the same output.

Example input

{
  "sources": [
    "https://example.com/annual-report.pdf",
    "https://example.com/price-list.xlsx"
  ],
  "outputFormat": "markdown",
  "ocr": "auto",
  "maxPages": 100
}

Anything that can't be processed becomes an error item with a code and a message that says what to change; the rest of the run carries on.

Pricing

Pay per event: you pay for results, not for compute time. Prices in USD.

EventPriceWhen
page-converted$0.002Each PDF page read from its text layer, each slide, each ~3,000-character section of DOCX, XLSX, HTML, CSV or text
ocr-page$0.006Each scanned page or image frame read with OCR (instead of page-converted)

A 20-page digital PDF costs $0.04. A 10-page scanned contract costs $0.06. A small 3-sheet workbook costs $0.006. Failed documents and pages over maxPages are never charged. When a run reaches the maximum total charge you set, it stops cleanly and marks what's left SPENDING_LIMIT_REACHED.

Limits

  • 50 MB per file, 1,000 sources per run, up to 500 pages, slides or sections per document.
  • Downloads time out after 60 s and follow up to 5 redirects; only public addresses are fetched.
  • Each document gets 15 minutes; pages done by then are returned with truncated: true.
  • Not supported yet: legacy .doc/.xls/.ppt, OpenDocument, EPUB, e-mail files, tables without ruling lines in PDFs, multi-column reading order in PDFs.

Use it from an AI agent

Through the Apify MCP server, Claude, ChatGPT, Cursor and other MCP clients can call this Actor as a tool. Add the server with this Actor enabled:

{
  "mcpServers": {
    "apify": {
      "url": "https://mcp.apify.com/?tools=tinplatelabs/document-to-markdown",
      "headers": {
        "Authorization": "Bearer <APIFY_TOKEN>"
      }
    }
  }
}

The agent calls it with {"sources": ["https://example.com/report.pdf"]} and reads the markdown field of the first dataset item.

Or call the Apify API directly. This runs the Actor and returns the dataset items (synchronous runs time out after 300 s; for big batches start a run and read the dataset when it finishes):

curl -s -X POST \
  "https://api.apify.com/v2/acts/tinplatelabs~document-to-markdown/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"sources": ["https://example.com/report.pdf"]}'

Privacy

Files are downloaded into your run, converted there and written only to the run's dataset and key-value store. No third party, no LLM, no telemetry; links inside documents are never followed. See also the privacy page.

FAQ

How do I convert a file that isn't online?

Upload it to an Apify key-value store, pick that store as keyValueStoreId and pass kvs://KEY as the source. A signed Apify record URL also works.

Are scanned PDFs supported?

Yes. With ocr: auto (the default) only pages without a text layer are OCRed with Tesseract, in any of 26 languages you list in ocrLanguages. Those pages cost $0.006 instead of $0.002.

Does an LLM see my documents?

No. Conversion is deterministic code (pdfplumber, PDFium, markitdown, Tesseract) running inside your Apify run. Nothing is sent to a third party.

How do I split the output for a vector database?

Set chunkByPage: true to get one dataset item per page, or use the pages offsets: markdown[startOffset:endOffset] is exactly that page's text.

What happens with a password-protected or old .doc file?

It returns an error item (ENCRYPTED or LEGACY_OFFICE_FORMAT) that says what to do, costs nothing, and the rest of the run carries on.
